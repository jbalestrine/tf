A comprehensive enterprise DevOps automation platform featuring multi-cloud infrastructure, AI-powered automation, real-time ChatOps, voice control, and a complete CI/CD pipeline orchestrator. MasterChief brings together the full DevOps lifecycle — Plan, Code, Build, Test, Release, Deploy, Operate, Monitor, Secure, Optimize — into one unified platform.

Current Features

Implemented pages and capabilities; external provider features still require account access and local configuration.

🤖

Echo AI Chat Bot

Conversational assistant using the model/runtime configured for this installation, with a local project-code library and explicit command handling. Drafts and training examples are not executed or trained automatically.

💬

Echo ChatServ

Browser-based rooms with hashed NickServ-style accounts, owner/OP moderation, room conversation roles, persona bots sharing Echo's configured model, a text-file MOTD, admin-only GGUF selection and allowlisted page transfers. ChatServ accounts do not grant platform admin access.

⚙️

DevOps Master Suite

10 phases, 74+ capabilities across the full DevOps lifecycle. From planning and code analysis to monitoring and security scanning, every phase is covered.

💻

Web IDE

Monaco-based code editor with Git integration. Edit files, browse repositories, and commit changes directly from the browser with syntax highlighting and IntelliSense.

🚀

Pipeline Orchestrator

ADO-inspired local pipeline studio with starter templates, parallel stages, run history, logs, YAML/JSON import and export, and manual approval gates. Terraform Apply always pauses for approval; triggers and remote deployment providers require separate configuration.

📊

Observability Center

Connect existing Prometheus, Grafana, and Loki services; scrape MasterChief HTTP metrics, run read-only PromQL and LogQL queries, and browse configured dashboards. Service URLs and tokens are configured server-side.

☁️

Multi-Cloud Dashboard

Cloud operations use the credentials each user supplies and are limited to resources those credentials can manage under provider IAM. MasterChief GOD access does not grant extra cloud permissions; provider APIs and configuration must also be available.

🔐

Secrets Vault

Secrets-management interface for locally configured credentials. Provider-specific storage, access policies, and rotation depend on the configured backend.

🧠

Echo Memory

Conversation memory and search interface. Stored history and retrieval depend on the configured storage and model services.

🛒

Plugin Marketplace

Browse and manage available add-ons and modules. External marketplace availability depends on configured sources.

🔔

Notification System

Notification settings and channel interfaces are available; delivery requires the selected provider's credentials and configuration.

🛡️

Access Control (RBAC)

Role-based permissions and user management. Define custom roles, assign granular permissions, and enforce least-privilege access across all platform features.

🏗️

Terraform Wizard

Guided infrastructure design, component selection, live Terraform previews, validation guidance, and downloadable modules. Generated code is review-first and never auto-applies infrastructure.

🗺

Architecture Blueprint Studio

Readable hub-and-spoke layouts group VNets and subnets, label peering links, and export diagrams as SVG or Visio. The same design model drives the Terraform preview.

🧩

Code Archetypes

Starter archetypes with component-flow diagrams, source previews, custom template creation, and explicit handoff to a developer editor.

💬

IRC ChatOps Engine

Optional TLS IRC bridge for Echo chat. It joins explicitly configured channels, relays /ai messages, and accepts private-message TOTP authentication for local app startup. Arbitrary shell commands are not enabled over IRC.

🎤

Voice Automation

Voice automation components and interfaces for wake words, speech processing, and audio workflows; supported actions depend on locally installed models and devices.

🎓

Training System

Training-data management plus an optional local LoRA adapter trainer for approved examples and compatible Hugging Face checkpoints. Training is explicit and does not overwrite base-model weights.

Updates Made — October 6, 2026

Local code and UI updates; service connections that require provider credentials have not been live-tested.

  • Added a searchable global navigation with Ctrl+K and / shortcuts, active-section highlighting, responsive dropdowns, and filtering for orphaned or unsafe pinned add-on links.
  • Added Azure CIDR overlap/containment, resource-name, duplicate RBAC assignment, and broad-role validation to the Terraform Wizard. Validation does not deploy cloud resources.
  • About now checks the latest GitHub release, or the default-branch commit if no release is published, and can be refreshed on demand.
  • Fixed Code UI browsing to use the project root consistently, added project-wide script search, and guarded project file paths.
  • Added a local source library for Echo, script drafting with !write, a function-oriented code wizard, and a clickable command catalog.
  • Added Echo ChatServ with persistent hashed-password accounts, room ownership and OP moderation, room prompts and persona bots, an editable commands/MOTD.txt, explicit !ask, safe page transfers, and RBAC-admin-only model selection.
  • Organized !commands into General, Code library, Model team, Operator controls, and add-on command groups.
  • Master-user deployment grants GOD access to authenticated users. Cloud operations remain limited to the provider permissions in each user's credentials; restrict network reachability to trusted clients.
  • Added an opt-in TLS IRC bridge. It supports Echo chat in configured channels and private messages; !masterchief requires a private-message, one-time authenticator code before starting the app.
  • The IRC-started web app binds to loopback only. The IRC listener itself must be started and kept running on your machine; no DALnet connection or IRC credentials have been configured.
  • Set the model team to Echo's existing local default model, with an option to add local Ollama models later. Model replies are queued for review rather than changing weights automatically.
  • Added an optional local Hugging Face/PEFT LoRA trainer that writes a separate adapter from approved examples; it does not overwrite the base model or install training packages automatically.
  • Kept SMS disabled by default and documented that GitHub stores source code but does not keep the Flask app running.
  • Added Google Calendar, Gmail, Voice, Translate, Meet, Drive, Docs, Sheets, Slides, Forms, Keep, Tasks, Contacts, Photos, Maps, Cloud Console, and account shortcuts. These open Google; Google API access inside MasterChief still needs OAuth configuration.
  • Updated Teams sign-in completion to return to Calendar and automatically load the selected date range using timezone-aware timestamps.
  • Fixed Okta app-link lookup to use the signed-in user identifier rather than the unsupported generic “me” path. A live Okta tenant/account is still needed to verify access.
  • Improved diagnostics by excluding named and versioned virtual environments, serializing cached scans, and removing duplicate diagnostics route registrations.
  • Added a Git SCM reference for inspection, everyday operations, backup/stash, and recovery commands.
  • Added the Code Archetypes page and launcher to the Web IDE, Terraform/ARM editors, and shared developer pages. Archetypes include diagrams and code previews; loading an existing editor's code requires confirmation.

Verification: 40 focused tests passed and one platform-dependent symlink test was skipped; the latest IRC/model-team subset passed 10 tests. A live IRC connection and model fine-tuning run still require local configuration and were not performed.
