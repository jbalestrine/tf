Site Settings

Change the logo, titles, version, About page text and menu without opening any file. Every change shows a diff first, keeps a backup, and lists the exact files it edits. Restore a backup from the Page Editor. Layout and Python changes take effect after you restart the app.

Review changes


    

    
    




    
Logo

    

        
        

            
            
            
SVG, PNG, JPG or WebP up to 1 MB. Saved as static/masterchief-logo.*; the old file is copied to data/page_editor_backups/. Header markup: main.py and templates/base.py.

        

    







    
Menu

    
Rename groups and links, change where a link goes, add a link under a group, or remove one. Edits HTML_TEMPLATE in main.py and the matching line in templates/base.py. Removing a menu link does not delete the page itself.
